# 钱迹强制周一 (Qianji Force Monday)

> **libxposed API 102** LSPosed 模块 —— 强制钱迹记账（com.mutangtech.qianji）每周第一天为**周一**。

## ✨ 功能

**强制锁定钱迹记账的"每周起始日"为周一**，解决设置固定不住（设了周一，过段时间/重开又变回周日）的问题。

- ✅ **日历页以周一起始**：打开钱迹日历，每周从周一开始排列
- ✅ **设置锁定不反弹**：选择周一后不会自动跳回周日
- ✅ **完全可逆**：不拦截写入、不修改账单数据；停用/卸载模块即恢复原样

> 📌 无 UI 开关，**启用模块即生效**；无需任何设置。

## ⚠️ 特殊情况

- 强制周一后，设置界面里的「周六 / 周日」选项**不生效**（属预期行为）
- 钱迹 App 更新后若类名混淆变化，模块可能失效，等待作者适配即可

## 🔧 安装使用

1. 安装 APK
2. LSPosed 管理器 → 模块 → 启用「钱迹强制周一」
3. 勾选作用域：**钱迹记账**（`com.mutangtech.qianji`）
4. 强制停止钱迹 → 重新打开
5. 打开日历页，确认周一起始 ✅

钱迹的「每周起始日」选择固定不住，官方多次反馈未修复，于是自己动手用 LSPosed Hook 强制锁定周一。
